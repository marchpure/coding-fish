# coding-fish

Codex skill for Meego-first AI coding orchestration.

It packages the Coding Fish operating model:

- Meego work item as curated job / cluster
- AI Ready gate before coding
- proposal-first execution by default
- MR-based human code review
- DevX dev acceptance and release review gates
- Proof Packet as audit artifact
